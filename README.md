# לו״ז מייקר — בטא

כלי קוד פתוח להפקת לוחות זמנים מתוכננים בתחבורה הציבורית.

## סטטוס
- ממשק בטא ב-`index.html`, בעברית ובתצוגה מותאמת לנייד.
- יצירת קבוצות קווים ושמירתן באמצעות localStorage.
- בחירה ידנית או קיבוץ אוטומטי של תאריכים עם לוחות זהים.
- תצוגת לוחות, יצוא CSV ושמירה כ-PDF באמצעות הדפסה.
- **כרגע רק נתוני הדגמה; אין להסתמך על הזמנים לנסיעה.**

## ממשק הנתונים הצפוי
דף האפליקציה מחפש `data/index.json`:
```json
{"updated":"2026-11-05","lines":["134","402"]}
```
ואז `data/lines/134.json` עבור כל מספר קו:
```json
{
  "routes": [
    {
      "id": "route-stable-id",
      "name": "כיוון המסלול",
      "stops": [{"id":"1552","name":"שם התחנה"}],
      "trips": {
        "1552": {
          "2026-11-05": [480, 540]
        }
      }
    }
  ]
}
```
ערכי הזמן כרגע הם דקות החל מ-00:00. לפני חיבור נתונים אמיתיים יש לטפל גם בימי שירות שחוצים חצות, בנסיעות מעל 24:00 ב-GTFS, בשינויים בימים חריגים, ובהתאמה של מזהי המסלולים/תחנות בין עדכונים.

## סדר העבודה הבא
1. לפתח מעבד GTFS רשמי, עם בדיקות תקינות ויצירת JSON.
2. לבדוק קווים, תחנות, תאריכים חריגים ונסיעות שחוצות חצות.
3. לפרסם נתונים דרך GitHub Pages ולחבר אליהם את הבטא.
4. לשפר תצוגת PDF וייצוא, נגישות ובקרת שגיאות.

תהליך העיבוד עדיין לא נבנה.
